# 길드원 캐릭터 실험 에셋

길드마스터 클리커 RPG 기획서의 길드원 데이터를 바탕으로 제작한 실험용 캐릭터 에셋 모음입니다. 원본 저장소 이름과 무관하게 실제 기획 내용의 `초기 길드원 데이터 예시`를 기준으로 정리했습니다.

## 포함 범위

- F~S 등급 길드원 25명의 전신 캐릭터 시안
- 첫 캐릭터 `견습 전사 로안`의 웹게임용 애니메이션
  - 대기 6프레임
  - 이동 8프레임
  - 기본 공격 8프레임
  - 고유 스킬 `강타` 10프레임
- 투명 PNG 개별 프레임과 스프라이트 시트
- 무손실 WebP 시트와 재생 미리보기
- 프레임 타이밍 및 기준점 JSON

## 폴더 구조

- [planning-source.md](planning-source.md): 기획서에서 추출한 직업·캐릭터 데이터와 작업 기준
- [character-concepts](character-concepts/README.md): 길드원 25명 캐릭터 시안
- [roan-animation](roan-animation/README.md): 로안 애니메이션 및 웹 적용 자료

## 아트 방향

- 모바일 방치형 판타지 RPG용 3등신 캐릭터
- 직업, 무기, 대표 스킬이 작은 화면에서도 구분되는 실루엣
- 등급이 높아질수록 장비 장식과 스킬 이펙트가 강해지는 구조
- UI, 글자, 로고, 워터마크가 없는 단독 캐릭터 이미지

> 이 폴더의 결과물은 프로덕션 확정본이 아닌 방향성 검토용 실험 에셋입니다. 실제 게임 적용 전 캐릭터 비율, 시점, 장비 고정 규칙과 애니메이션 타이밍을 아트 파이프라인에 맞춰 재검토해야 합니다.
