# 길드원 에셋 작업 기준

## 기획 요약

플레이어는 길드마스터가 되어 몬스터를 직접 클릭 공격하고, 고용한 길드원을 최대 4명까지 편성해 자동 전투를 진행합니다. 길드원은 직업, 등급, 공격 주기, 기본 공격과 고유 스킬을 가지며 전투 참여를 통해 성장합니다.

길드원 등급은 `F → E → D → C → B → A → S` 순서입니다. 낮은 등급은 소박하고 실용적인 장비, 높은 등급은 선명한 속성 효과와 복잡한 장비 장식으로 차이를 표현했습니다.

## 이미지 생성 기준

공통 프롬프트는 모바일 방치형 판타지 RPG 캐릭터, 프리미엄 2D 디지털 게임 일러스트, 3등신 전신 비율, 선명한 실루엣, 3/4 시점, 단독 캐릭터와 중성 배경을 기준으로 구성했습니다. 각 캐릭터의 이름, 등급, 직업, 무기, 공격 특징, 고유 스킬과 대표 색상을 개별 프롬프트에 결합했습니다.

로안 애니메이션은 캐릭터 시안을 기준 이미지로 사용해 얼굴, 갈색 머리, 낡은 철검, 원형 목제 방패, 패치된 갈색 가죽옷, 크림색 소매와 적갈색 스카프를 유지하도록 생성했습니다. 생성 원본의 크로마키 배경을 제거한 뒤 256×256px 투명 프레임으로 정규화했습니다.
