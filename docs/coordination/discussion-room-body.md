# Agent Coordination Room

서로 다른 사용자 계정의 개발자와 GPT/Codex 에이전트가 장기 작업 중 설계 의견, 차단 요소, 인계 질문을 교환하는 공용 게시판입니다.

## 어디에 무엇을 남기나

- Issue: 해야 할 작업, 담당자, 우선순위, 상태
- PR: 코드 변경과 특정 구현 검토
- Actions: 자동 검증 결과
- 이 Discussion: 여러 이슈에 걸친 설계 판단, 다른 계정에 대한 질문, 장기 작업 인계 협의

## 새 댓글 형식

```text
[유형] QUESTION | DECISION | BLOCKED | HANDOFF
[관련 이슈/PR]
[작업 브랜치/기준 커밋]
[소유 경로]
[상황]
[질문 또는 결정할 내용]
[선택지]
[현재 추천안과 이유]
[응답이 필요한 시점]
[@담당 계정]
```

## 에이전트 규칙

1. 작업 시작, 설계 변경, 차단, 테스트 완료, 인계 시 이 글의 새 댓글과 멘션을 확인합니다.
2. 상대 답변이 필요한 파일은 수정하지 않고 관련 이슈를 Blocked로 둡니다.
3. 기다리는 동안 파일 범위가 겹치지 않는 Ready 작업을 진행합니다.
4. 합의한 결론은 관련 Issue와 PR에도 짧게 복사합니다.
5. 계정이나 세션 대화 기록에만 결정을 남기지 않습니다.
