# desk64 AI 활용 세션 취합본

이 디렉터리는 NHN2026 제출용 AI 활용 기술문서 작성을 위해 `desk64`에 남아 있던 Clicker Guild 관련 Codex 대화를 비식별 요약한 자료다. 원본 대화는 포함하지 않았으며, GitHub Issue #141의 여러 PC 취합 과정에서 사용할 수 있도록 사람용 요약과 기계 병합용 JSONL을 함께 제공한다.

## 범위

- 장비 별명: `desk64`
- 대상 기간: 2026-08-09~2026-08-10
- 컷오프: 2026-08-10 19:38:37 KST
- 논리 세션: 11개
- 실질 사용자 요청: 115개
- 사용자에게 표시된 assistant 진행·결과 메시지: 439개
- 현재 취합 세션: 제외

여러 JSONL 파일로 반복 저장된 후속 턴, 포크, 보조 에이전트 기록은 세션 ID 기준으로 묶어 중복 계산하지 않았다. 보조 작업의 원문은 별도 세션으로 싣지 않고 사용자에게 보인 최종 설계·구현·검증 결과만 상위 세션 요약에 반영했다.

## 파일

- `summary.md`: NHN2026 기술문서에 바로 활용할 수 있는 전체 서술형 압축본
- `technical-notes.md`: AI가 쓰인 위치, 앱·오디오·피날레 구조, 개발·검증 흐름
- `prompt-catalog.md`: 주요 프롬프트·상시 지시와 인간 피드백을 정확 문구/재구성으로 구분한 카탈로그
- `external-sources.md`: 외부 에셋·AI 생성물·오픈소스의 출처, 이용 조건, 증빙 공백 감사
- `session-summaries.jsonl`: PC별 결과 병합을 위한 세션 단위 구조화 요약
- `manifest.json`: 범위, 집계, 제외 정책, 스키마 정보
- `validation-report.md`: 개인정보·인증정보 제거와 형식 검증 결과
- `desk64-ai-session-evidence.zip`: 위 문서와 이 README의 전달용 압축본
- `SHA256SUMS.txt`: 원본 파일과 ZIP의 무결성 확인값

## 병합 방법

1. `SHA256SUMS.txt`로 파일 손상 여부를 확인한다.
2. `validation-report.md`의 제한사항과 수동 검토 항목을 확인한다.
3. 다른 PC의 JSONL과 `schema_version`이 같을 때 `session-summaries.jsonl`을 줄 단위로 합친다.
4. `machine_alias`와 `session_id`의 조합을 병합 키로 사용한다.
5. `summary.md`를 전체 개요로, `technical-notes.md`, `prompt-catalog.md`, `external-sources.md`를 PDF의 세부 장 근거로 사용한다.
6. 중앙 #141 작업에서 최종 스키마가 달라지면 원문 세션이 아니라 이 비식별 요약을 새 스키마로 변환한다.

개별 텍스트 파일의 SHA-256은 ZIP 안에 들어간 정확한 바이트를 기준으로 한다. Git 설정이 줄바꿈을 변환하는 운영체제에서는 체크아웃 파일의 값이 달라질 수 있으므로, 먼저 ZIP 자체의 해시를 확인한 뒤 ZIP 내부 파일을 기준으로 대조한다.

## 제출문서 완성도

기술 구조와 주요 AI 활용 사례는 현재 자료만으로 초안을 작성할 수 있다. 프롬프트는 정확 문구가 남은 항목과 여러 대화를 합친 비식별 재구성을 구분했다. 다만 외부 에셋 출처는 아직 완결되지 않았다. Flow Music·ImageGen 생성 기록과 일부 이용 조건, 다수 이미지의 제작 출처, 통합 OSS 고지가 부족하므로 `external-sources.md`의 필수 보완 목록을 최종 PDF 작성 전에 해결해야 한다.

## 개인정보 보호 원칙

- 사용자 요청과 assistant 결과를 그대로 인용하지 않고 의미만 새 문장으로 재서술했다.
- 시스템·개발자 지시, 내부 추론, 도구 입력·출력, 브라우저 주변 상태, 세션·스레드 식별자, 원본 첨부 파일은 제외했다.
- 로컬 절대경로, 실제 사용자·계정·PC 이름, 주소, 이메일, 전화번호, 인증정보, 개인·세션 공유 URL은 포함하지 않았다.
- 출처 감사에 필요한 제작사 공식 페이지, 공개 라이선스, 공개 생성물 원본 페이지 URL만 예외적으로 보존했다. 이 URL의 식별자는 로컬 세션 ID가 아니다.
- 공개 프로젝트 안에서 재현에 필요한 Issue·PR 번호, 브랜치명, 짧은 작업 상태만 보존했다.
- 자동 탐지에는 한계가 있으므로 NHN2026 제출 전 사람이 한 번 더 읽고 확인해야 한다.
