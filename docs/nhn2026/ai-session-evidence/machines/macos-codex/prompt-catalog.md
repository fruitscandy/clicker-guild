# 주요 프롬프트와 지시 사항 카탈로그 — macos-codex

이 문서는 NHN2026 「AI 대상 주요 프롬프트 및 지시 사항」 항목에 활용할 수 있도록 이 macOS 장비의 Clicker Guild 세션을 비식별 재구성한 것이다. 시스템·개발자 지시, 내부 추론, 도구 호출, 개인정보가 포함된 원문은 싣지 않았다.

## 읽는 방법

- **비식별 재구성**: 여러 사용자 발화와 후속 피드백을 하나의 재사용 가능한 프롬프트로 새로 쓴 것이다. 실제 한 번의 발화를 그대로 인용한 것이 아니다.
- **저장소 보존 문구**: 공개 저장소에 이미 기록된 생성 프롬프트 중 개인정보가 없는 문구다.
- 각 항목에 인간 피드백과 결과를 함께 적어 AI 출력이 자동 채택되지 않았음을 표시한다.

## 공통 구현 지시

**표현 수준:** 비식별 재구성

> 공개 저장소의 최신 코드와 진행 중 작업을 먼저 확인하라. 수정 경로가 겹치지 않는 독립 작업공간과 브랜치에서 구현하고, 에셋은 출처·manifest·후처리 정보를 함께 남겨라. 변경 뒤 관련 테스트, lint, production build와 데스크톱·모바일 미리보기를 확인하라. 사람이 화면 또는 소리를 검토해 승인한 뒤에만 병합하라.

이 내용은 대화의 비공개 상시 지시를 옮긴 것이 아니라 저장소의 `AGENTS.md`와 `docs/coordination/README.md`, 여러 사용자 피드백에 반복해서 나타난 공개 작업 방식의 요약이다.

## 1. 길드마스터 클리커 RPG 기획

**표현 수준:** 비식별 재구성

> 플레이어가 길드마스터가 되어 직접 클릭 공격하고, 고용한 길드원은 자동 공격하는 클리커 RPG를 설계하라. 화면은 성장하는 길드 영지와 스테이지 토벌 필드로 나눈다. 고용, 파티 편성, 장비 파밍, 무기 강화, 보스 보상과 영지 성장을 하나의 루프로 연결하라. 전체 기획과 하루 안에 구현할 MVP를 분리하라.

- AI 활용: 핵심 게임 루프, 화면, 성장, 데이터, 보스와 MVP 우선순위를 문서화했다.
- 인간 결정: 직접 공격과 길드원 자동 공격의 역할, 영지 성장의 시각적 중요성, 장기 기획과 당일 MVP의 범위를 정했다.

## 2. 길드원 25명 연결 애니메이션

**표현 수준:** 비식별 재구성

> 저장소의 캐릭터 기획과 기존 시안을 읽고 길드원마다 대기, 이동, 기본 공격, 고유 스킬 애니메이션을 만들어라. 이름·등급·직업·무기·대표 색과 스킬이 작은 화면에서도 구분돼야 한다. 캐릭터별 프레임, 스프라이트 시트, 연결 미리보기, 런타임 매핑을 함께 제공하라.

- AI 활용: 25명 각각의 이미지 입력을 구성하고 투명 프레임·WebP·연결 미리보기와 상태 매핑을 만들었다.
- 인간 피드백: 실제 전투에서는 길드원 본체가 아니라 패시브 공격과 스킬만 표시된다는 구조를 다시 명확히 했다.

## 3. 몬스터·필드·길드 성장 에셋

**표현 수준:** 비식별 재구성

> 기존 캐릭터와 게임 UI의 따뜻한 판타지 톤을 참고해 몬스터, 필드, 길드 성장 이미지를 제작하라. 몬스터는 작은 화면에서도 종족과 무기가 읽혀야 하고 피격·사망 반응을 가져야 한다. 필드는 전투 중앙을 비우고 지역별 환경을 가장자리에 배치하라. 길드는 업그레이드마다 실제 게임 안에서 조금씩 커지는 투명 스프라이트와 애니메이션이어야 한다.

- AI 활용: 28종 몬스터, 10개 지역 필드, 6단계 길드 성장 자산과 런타임 연결을 만들었다.
- 인간 피드백: 홍보물 같은 길드 초안을 게임용 스프라이트로, 평면적인 필드를 고품질 손그림 배경으로 다시 만들게 했다.

### 1지역 몬스터 공통 생성 문구

**표현 수준:** 저장소 보존 문구

```text
Use case: stylized-concept
Asset type: production-ready 2D monster asset for a fantasy guild clicker RPG
Style/medium: polished hand-painted mobile RPG illustration, crisp chunky silhouette,
bold dark contour, bright cel shading, friendly expressive proportions
Composition/framing: exactly one creature, centered full-body front three-quarter view,
generous padding, square canvas, readable at small game scale
Lighting/mood: bright whimsical beginner-forest mood
Constraints: no ground, no cast or contact shadow, no scenery, no frame, no UI,
no text, no numbers, no logo, no watermark
```

이 문구는 `docs/experimental-asset/stage-01-beginners-forest/image-generation-guide.md`에 보존돼 있다. 실제 파일별 변형 문구와 모델 세부값은 완전하게 남아 있지 않다.

## 4. 핵앤슬래시 클릭 전투와 15단계 무기

**표현 수준:** 비식별 재구성

> 필드에 몬스터 무리를 배치하고 정확한 체력과 잔여 수는 숨겨라. 클릭 위치를 중심으로 공격 범위를 만들고 범위 안의 몬스터를 동시에 타격하라. 플레이어 무기는 15단계로 구성해 강화할수록 공격력과 연출·타격음이 강해지게 하되, 실제 공격 범위는 별도 발전 노드만 바꾸게 하라. 무기별 외형, 커서, 대장간 UI와 반복 클릭 회귀 테스트를 제공하라.

- AI 활용: 다중 몬스터, 범위 판정, 치명타·연격·처형, 무기 데이터와 VFX·오디오 레이어를 구현했다.
- 인간 피드백: 이펙트와 판정 좌표가 어긋나는 문제, 반복 피격이 한 번만 보이는 문제, 상위 무기가 서로 비슷한 문제를 실제 화면에서 지적했다.

## 5. 번개·토네이도·운석 특수 비술

**표현 수준:** 비식별 재구성

> 발전 노드에 번개 강타, 토네이도, 운석 충돌을 추가하라. 번개는 여러 몬스터를 연쇄 감전시키고, 토네이도는 몬스터를 회전·견인하며, 운석은 광역 피해와 강한 넉백을 주되 전장 밖으로 밀어내지 않게 하라. 각각 별도 쿨다운, HUD, 사운드와 읽기 쉬운 화려한 연출을 제공하라.

- AI 활용: 전투 상태·쿨다운·대상 선택·넉백 경계와 Kenney CC0 파티클·AI 생성 그림을 합성했다.
- 인간 피드백: 이후 다른 세션에서 VFX가 너무 크고 길다는 평가가 나와 크기와 쿨다운을 다시 조정했다.

## 6. 전리품 드롭·회수와 소재 경제

**표현 수준:** 비식별 재구성

> 몬스터 처치 위치에 골드와 지역 재료가 떨어지고 토벌 완료 뒤 화면 상단으로 순차 회수되게 하라. 도착 시점에 실제 재화를 저장하고 후퇴·재시작 때 남은 드롭을 정리하라. 스테이지가 높아지면 동전, 주머니, 돈뭉치의 형태와 소리를 바꾸고, 10개 지역 소재를 무기 강화 비용과 연결하라. 전체 게임이 10~20분 안에 끝나도록 첫 제작과 성장 비용을 맞춰라.

- AI 활용: 전리품 상태 머신, CSS 이동, Web Audio, ImageGen 소재 아틀라스, 저장 마이그레이션과 경제 밸런스를 구현했다.
- 인간 피드백: 첫 합성음이 동전처럼 들리지 않고 아이콘의 사각 프레임이 거슬린다고 평가해 CC0 실녹음과 컷아웃 아틀라스로 교체했다.

## 7. 여관과 영지 사냥터 UI

**표현 수준:** 비식별 재구성

> 사용하지 않는 훈련장을 제거하고 여관에서 신규 고용, 보유 인원, 4인 파티 편성을 한 번에 처리하게 하라. 캐릭터 초상화 비율을 통일하고 도형 장식 대신 목재·양피지 기반 판타지 UI를 사용하라. 메인 화면의 중복 헤더는 제거하고 길드 영지 안의 사냥터 건물을 클릭해 지역 선택과 출정을 시작하게 하라.

- AI 활용: 여관 정보 구조, 초상화·건물 이미지, 사냥터 전초기지와 화면 전환을 구현했다.
- 인간 피드백: 첫 사냥터 그림이 사냥터처럼 보이지 않는다고 평가해 목책, 무기, 덫, 정찰 천막 중심으로 재생성했다.

## 8. 세계 소멸 오프닝

**표현 수준:** 비식별 재구성

> 게임 세계에서 길드와 지역이 하나씩 지워지고 마지막 길드만 남는 사실을 짧고 직관적으로 보여라. 누가 왜 지우는지, 최종 보스가 AI인지, 최종전이 어떻게 진행되는지는 오프닝에서 밝히지 마라. 여러 길드의 불빛이 사라지고 마지막 길드만 점등된 뒤 “몬스터를 토벌하고 마지막 길드를 성장시키세요”로 끝내라.

- AI 활용: 여러 복잡한 서사안을 비교하고 장면·문구·타이밍·사운드를 실제 오프닝으로 구현했다.
- 인간 피드백: 기록, 아카이브, 제작자 없는 에셋 같은 과도한 설정을 거듭 제거하고 가장 단순한 세계 소멸 이야기로 수렴시켰다.

## 9. 첫 플레이 튜토리얼

**표현 수준:** 비식별 재구성

> 오프닝 뒤 사냥터를 강조하고 1-1 스테이지 선택, 몬스터 클릭 공격, 전투 승리, 여관 무료 10연 영입, 대장간 첫 무기 제작 순으로 안내하라. 현재 목표 영역 밖은 어둡게 표시하고 클릭·스크롤을 막아라. 기존 저장과 새 게임을 구분하고, 안내 문구가 몬스터나 핵심 UI를 가리지 않게 하라.

- AI 활용: 단계 상태, spotlight 좌표, 포인터 차단, 화면 전환과 저장 플래그를 구현했다.
- 인간 피드백: 전투 문구 위치와 여관 영입 UI의 불필요한 여백·아이콘·초상화 깜빡임을 직접 지적했다.

## 10. 길드원 25종 스킬 VFX

**표현 수준:** 비식별 재구성

> 길드원 25명의 직업, 무기, 고유 스킬과 전투 톤에 맞는 투명 스킬 VFX를 만들어라. 파일명과 멤버 ID를 manifest로 연결하고 기본 공격과 쿨다운 스킬을 구분하라. 작은 화면에서 사진 한 장이 나타나는 느낌이 들지 않도록 짧은 진입, 타격, 잔광 모션을 합성하라.

- AI 활용: ImageGen WebP 25종, 알파 후처리, manifest, 기본 공격·스킬 런타임 선택과 CSS 모션을 구현했다.
- 인간 피드백: 첫 런타임 결과가 너무 크고 정적인 이미지처럼 보인다고 평가해 기본 공격과 스킬 모두 크기·지속시간을 절반 이하로 줄였다.

## 11. 게임 오디오 믹스

**표현 수준:** 비식별 재구성

> 무기 제작은 망치와 금속 공명, 길드 승급은 석재 충격과 짧은 팡파르가 들리게 하라. 토벌 시작·실패·고용·메뉴·승리음도 빈 경로 없이 채워라. BGM이 SFX를 덮지 않게 전체 믹스를 조정하되 기존 음량 슬라이더와 0% 완전 음소거를 유지하라.

- AI 활용: Web Audio 합성음과 CC0 실녹음을 공통 SFX 설정에 연결하고 gain·pitch·filter·reverb·compressor를 조합했다.
- 인간 피드백: 합성 중심 칼소리와 동전소리의 실재감 부족, BGM과 SFX의 상대 음량을 청감으로 교정했다.

## 제출 전에 보강해야 할 프롬프트 정보

- 다수 ImageGen 파일의 정확한 모델 버전, seed, 생성 작업 ID, 생성 시각과 전체 원문 프롬프트가 없다.
- 캐릭터·필드·길드 시설의 기준 이미지가 프로젝트 소유 자료였다는 문장은 있으나 파일별 참조 입력 목록과 권리 선언이 없다.
- AI 생성 결과의 유사성·상표·제3자 캐릭터 혼입 여부를 사람이 검토한 체크리스트가 없다.
- 합성 오디오의 설계 지시는 대화 요약에 남지만 모든 파라미터가 독립 문서나 재생성 스크립트로 보존된 것은 아니다.
- 위 프롬프트는 개인정보 보호를 위한 재구성본이므로 원문 발화의 정확한 인용 증빙으로 사용하면 안 된다.
