# macos-codex AI 활용 세션 취합본

이 디렉터리는 NHN2026 제출용 AI 활용 기술문서 작성을 위해 이 macOS 장비에 남아 있던 Clicker Guild 관련 Codex 대화를 비식별 요약한 자료다. 원본 대화는 포함하지 않았으며, Issue #141의 Windows 자료와 합칠 수 있도록 사람용 문서와 기계 병합용 JSONL을 함께 제공한다.

## 범위

- 장비 별명: `macos-codex`
- 대상 기간: 2026-08-08~2026-08-10
- 컷오프: 2026-08-10 20:44:45 KST
- 논리 세션: 9개
- 실질 사용자 요청: 151개
- 사용자에게 표시된 assistant 진행·결과 메시지: 795개
- 현재 및 선행 증빙 취합 세션: 제외

동일한 기획 요청이 중복 저장된 기록은 한 세션으로 합쳤다. 같은 목적의 개발환경 점검 두 건도 하나의 논리 세션으로 묶되 실제 사용자 요청 수는 모두 보존했다. 포크·보조 에이전트·승인 검토 기록은 별도 세션으로 계산하지 않았다.

## 파일

- `summary.md`: 세션 전체의 서술형 압축본과 세션별 결과
- `technical-notes.md`: AI 활용 구조, 이미지·코드·검증 파이프라인, 대표 구현 사례
- `prompt-catalog.md`: 주요 사용자 프롬프트와 반복 지시의 비식별 재구성
- `external-sources.md`: 외부 에셋, AI 생성물, 자체 생성물, 오픈소스 출처 감사
- `session-summaries.jsonl`: 장비별 결과 병합용 세션 단위 구조화 요약
- `manifest.json`: 범위, 집계, 제외 정책, 스키마 정보
- `validation-report.md`: 형식·민감정보·무결성 검증 결과
- `macos-codex-ai-session-evidence.zip`: 위 문서와 README의 전달용 압축본
- `SHA256SUMS.txt`: 문서와 ZIP의 SHA-256

## Windows 자료와 병합

1. 두 장비의 `SHA256SUMS.txt`와 `validation-report.md`를 먼저 확인한다.
2. `schema_version`이 같은 `session-summaries.jsonl`을 줄 단위로 합친다.
3. `machine_alias`와 `session_id` 조합을 병합 키로 사용한다.
4. 동일 PR·Issue·기능을 다룬 기록은 장비 간 중복 후보로 표시하되, 사람의 피드백과 장비별 검증 내용은 자동 삭제하지 않는다.
5. 기술문서 본문은 `technical-notes.md`와 `prompt-catalog.md`를 주제별로 통합한다.
6. 출처 표는 두 장비의 `external-sources.md` 중 더 강한 증빙을 채택하고, `부분 확인`·`미확인` 항목은 최종 체크리스트에 남긴다.

## 개인정보 보호 원칙

- 사용자 요청과 assistant 결과는 필요한 의미만 새 문장으로 재서술했다.
- 시스템·개발자 지시, 내부 추론, 도구 인수·원시 출력, 승인 검토 대화, 첨부 바이너리는 제외했다.
- 원본 세션·스레드 식별자, 실제 사용자·계정·장비 이름, 로컬 절대경로, 이메일, 전화번호, 인증정보, 로컬 서버 주소를 싣지 않았다.
- 공개 프로젝트의 Issue·PR 번호, 저장소 상대경로, 외부 에셋의 공식 원본 URL과 표준 라이선스는 재현성과 출처 증빙을 위해 보존했다.
- 자동 탐지는 알려지지 않은 개인정보 형식을 완전히 보장하지 않으므로 최종 제출 전에 사람이 다시 읽어야 한다.

## 제출 준비 상태

AI 활용 구조와 주요 프롬프트는 PDF 초안에 사용할 수 있다. 외부 출처는 CC0 오디오·파티클과 일부 생성형 에셋군까지 확인했지만, 다수 이미지의 파일별 모델·프롬프트·참조 입력·후처리·권리 검토 대장이 없다. 실제 제출 빌드 기준의 SBOM과 OSS 고지도 별도로 만들어야 한다. 자세한 차단 항목은 `external-sources.md` 마지막 체크리스트에 있다.
